# 欢迎来到王晨的学习中心

这里是我存放学习笔记的地方。我是计算机专业的学生，会用这个站点记录计算机专业知识、项目实战经验，以及生活方面的学习心得。

所有内容都用 **Markdown** 编写，通过 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 生成静态网站，托管在 GitHub Pages 上。

## 站点内容

- **数学** — 高等数学、线性代数、概率论与数理统计、离散数学（考研数学 + 计算机相关）
- **计算机基础** — 408 四门课：数据结构、计算机组成原理、操作系统、计算机网络
- **人工智能** — 机器学习、深度学习
- **项目实战** — Java 项目、AI 项目、Web 开发
- **开发工具** — Git、Docker 等常用工具
- **语言与表达** — 英语学习、口才训练
- **生活** — 健身、养生、做饭
